# Инструментарий перевода

Скрипты и конвенции для перевода буддологических текстов на русский. Здесь только
инструменты: они универсальны и ничьих прав не нарушают.

**Данных здесь нет и быть не должно.** Конкретные книги под копирайтом и переводы для
личного чтения живут в отдельном приватном репозитории (`bibliotheca-buddhica-privat`).
Разделение сделано папками, а не gitignore: единственная надёжная защита от случайной
публикации — физическое отсутствие файла в дереве публичного репозитория.

Переводы текстов из общественного достояния — другое дело, они публикуемы и лежат в
`texts/` как обычные тома серии.

## Зачем это, если модель и так переводит

Проблема буддологического перевода не в том, что модель не знает слова «дхарма». Проблема в
согласованности: в русской традиции есть конкурирующие переводческие конвенции, и выбор между
ними — теоретическая позиция, а не вопрос вкуса.

| Термин | Варианты | Кто так делает |
|---|---|---|
| `dharma` | «дхарма» / «элемент» | Розенберг и Щербатской переводят «элемент» |
| `saṃskāra` | «силы» / «формирующие факторы» / «санскары» | «силы» — Розенберг |
| `svabhāva` | «своебытие» / «собственная природа» / «самосущее» | «своебытие» — Андросов |
| `pramāṇa` | «источник верного знания» / «инструмент познания» | |
| `vikalpa` | «мысленное конструирование» / «концептуализация» | |

Без внешнего ограничения модель смешает конвенции внутри одной главы. Для человека в теме
текст станет нечитаемым, а для человека не в теме останется гладким — вот это и опасно.

Отсюда принцип: глоссарий фиксируется **до** перевода и проверяется скриптом **после**, а не
держится на добросовестности модели.

## Конвейер

1. **Глоссарий.** 150–300 позиций: английский термин → русский вариант → источник конвенции →
   запрещённые варианты. Собирается полуавтоматически (частотный список технических слов и
   санскрита), фиксируется человеком.
2. **Перевод по абзацам** с глоссарием в контексте. Не главами целиком: нужна привязка
   абзац-к-абзацу для сверки.
3. **Критик отдельным вызовом.** Сверяет русский абзац с английским, ищет смысловые сдвиги,
   проверяет глоссарий. Обязательно новый контекст — иначе он согласится сам с собой.
4. **Линтер** (скрипт, не модель): отклонения от глоссария, разнобой транслитерации, остатки
   английского, несогласованные имена.
5. **Ручная выборочная сверка.** Без неё качество неизвестно, а не «хорошее».

## Глоссарии — по традициям, а не по книгам

Важно и неочевидно: **палийская и санскритская традиции требуют разных глоссариев.**

- Щербатской, Westerhoff, Siderits — санскритская линия: `dharma`, `svabhāva`, `citta`.
  Эталон конвенции для Щербатского — его собственная «Теория познания и логика» (1903, 1909),
  где он сам решил, как передавать по-русски каждый термин Дхармакирти.
- Ronkin — палийская тхеравада: `dhamma`, `sabhāva`, `cetasika`. Здесь Щербатской не эталон,
  нужна русская палийская конвенция (переводы Парибка и прочая тхеравадинская литература).

Смешивать их в одном файле нельзя: `dhamma` и `dharma` — не опечатка друг друга, а разные
традиции с разной терминологией.

## Что конвейер гарантирует и чего не гарантирует

**Гарантирует:** согласованность терминологии (механически, линтером) и отсутствие
пропущенных абзацев.

**Не гарантирует:** правильность. Плохой философский перевод читается нормально —
`constructed` как «сконструированный» вместо «конструируемый» переносит акцент с процесса на
результат, и аргументация плывёт незаметно. Ловится только человеком, знающим предмет.

Поэтому: результат конвейера годен для личного чтения сразу, для публикации — только после
ручной сверки с замером ошибок на страницу.
